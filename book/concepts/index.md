# 概念 (Concepts)

在本章中，您將學習 Sui 和 Move 的基本概念。您將了解什麼是套件、如何與其互動、什麼是帳號和交易，以及數據如何在 Sui 上存儲。雖然本章不是完整的參考資料，您應該參考 [Sui 官方文件](https://docs.sui.io) 以獲得完整資訊，但它將讓您對在 Sui 上編寫 Move 程式所需的基本概念有很好的理解。
