# 概念 (Concepts) {#concepts}

在本章中，你將學習 Sui 和 Move 的基本概念：什麼是 package 以及如何與它互動、什麼是帳戶（account）和交易（transaction），以及資料如何儲存在 Sui 上。雖然本章並非完整的參考資料——如需完整參考資料請查閱 [Sui Documentation](https://docs.sui.io)——但它會讓你充分理解在 Sui 上撰寫 Move 程式所需的概念。
