# 附錄 F：致謝 (Appendix F: Acknowledgements) {#appendix-f-acknowledgements}

[The Rust Book](https://doc.rust-lang.org/book) 一直是本書很大的靈感來源。我個人非常感謝該書的作者 Steve Klabnik 與 Carol Nichols，因為我從中學到了很多。本書是對他們作品的一份小小致敬，也是希望能為 Move 社群帶來類似學習體驗的嘗試。

## Move 社群 (The Move Community) {#the-move-community}

同樣重要的是 Move 社群，從第一版開始就一直在塑造這本書——當時這個語言還沒有官方文件。那些提出問題、指出令人困惑段落、回報錯誤、開 issue 與 pull request 的讀者們，造就了今天的這本書。完整的貢獻者名單可以在
[GitHub](https://github.com/MystenLabs/move-book/graphs/contributors) 上找到，而
[貢獻](./contributing) 附錄則說明了如何加入他們。

最後，若沒有那些創造 Move 並持續開發至今的人——原始的 Move 團隊以及眾多推動這個語言前進的貢獻者，這一切都不會存在。與本書一同發布的
[Move Reference](/reference) 便是改編自他們的成果。
