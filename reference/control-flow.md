# 控制流 (Control Flow)

Move 基於 [布林運算式](./primitive-types/bool) 提供了多種控制流結構，包括常見的程式設計結構如 `if` 運算式、`while` 和 `for` 迴圈，以及進階控制流結構如迴圈標籤和可逃逸具名區塊。它還支援基於結構化模式匹配的更複雜結構。

- [模式匹配 (Pattern Matching)](./control-flow/pattern-matching)
- [迴圈 (Loops)](./control-flow/loops)
- [標籤控制流 (Labeled Control FLow)](./control-flow/labeled-control-flow)
