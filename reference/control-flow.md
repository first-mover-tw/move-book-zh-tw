# 控制流 (Control Flow)

Move 提供了多種基於 [布林表達式 (boolean expressions)](./primitive-types/bool) 的控制流結構，包括常見的程式設計結構，如 `if` 表達式、`while` 和 `for` 循環，以及進階的控制流結構，包括用於循環的標籤 (labels) 和可跳出的命名區塊。它還支持基於結構化模式匹配 (structural pattern matching) 的更複雜結構。

- [條件表達式 (Conditional Expressions)](./control-flow/conditionals)
- [模式匹配 (Pattern Matching)](./control-flow/pattern-matching)
- [循環 (Loops)](./control-flow/loops)
- [帶標籤的控制流 (Labeled Control Flow)](./control-flow/labeled-control-flow)
