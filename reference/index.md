# Move 參考手冊 (The Move Reference)

歡迎來到 Move，這是為安全資產編程而設計的下一代語言。它的主要使用場景是在區塊鏈環境中，Move 程式被用來建構狀態變更。Move 允許開發者編寫能靈活管理與轉移資產的程式，同時提供抵禦針對這些資產攻擊的安全性與保護。然而，Move 的開發也考慮到了區塊鏈背景以外的使用場景。

Move 借鑒了 [Rust](https://www.rust-lang.org/)，使用具有移動 (Move，因此得名) 語義的資源類型，作為數位資產（如貨幣）的明確表示。
