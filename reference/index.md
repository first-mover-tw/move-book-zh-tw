# Move 參考手冊 (The Move Reference)

_由 Move 貢獻者撰寫，並在 Move 社群的貢獻下為 Sui 進行改編_

歡迎來到 Move，這是一種用於安全資產程式設計的新一代語言。它的主要用途是在區塊鏈環境中，Move 程式被用來建構狀態變更。Move 允許開發者編寫能夠靈活管理和轉移資產的程式，同時提供安全性和針對這些資產攻擊的保護。然而，Move 在開發時也考慮到了區塊鏈背景之外的使用案例。

Move 借鑒了 [Rust](https://www.rust-lang.org/)，使用具有移動（move，語言名稱由此而來）語義的資源型別，作為數位資產（如貨幣）的明確表示。
